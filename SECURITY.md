# Security Policy

Only the latest release line gets security fixes. The project is
pre-1.0 and maintained as a hobby, so fixes land on a best-effort
basis through the normal release flow.

Found something? Do not open a public issue. Report it through
[private vulnerability reporting](https://github.com/stefanwalther/ghn/security/advisories/new),
which stays visible only to the maintainer until fixed. That page
goes live once the repo is public and reporting is enabled in the
repo settings.
